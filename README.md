# Qurbani Management System 🐐🐄🐪

## Overview

The Qurbani Management System is a console-based application developed in **C++** using **Object-Oriented Programming (OOP)** concepts. The system helps users select Qurbani animals, calculate prices and cutting charges, donate to needy families, and complete payments through different payment methods.

---

## Features

* Animal Selection (Goat, Cow, Camel)
* Automatic Price & Cutting Charge Calculation
* Donation Option for Needy Families & Children
* Final Bill Generation
* Card Payment & Cash on Delivery Options
* Secure Card Number Masking
* User-Friendly Console Interface
